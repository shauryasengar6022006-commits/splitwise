# 🔮 Splitwise "What-If" Expense Simulator & Feasibility Engine

A feature prototype for Splitwise enabling group pre-trip financial simulation, activity-level exclusions, dynamic risk analysis, and debt sponsorship before committing to expenses.

## 🚀 Key Features
- **3-Way Scenario Modeling**: Side-by-side comparison of customizable plans (Option A vs. Option B vs. Option C) in Indian Rupees (₹).
- **Per-Activity Inclusion & Opt-Out**: Exclude non-participating friends from specific activities (e.g., scuba diving, drinks) and redistribute costs strictly among attendees.
- **Happiness & Feasibility Meter (0–100%)**: Visual semi-circle gauge reflecting financial feasibility (<30% Sad, 30–60% Moderate, 60–90% Happy, 90–100% Amazing).
- **20% Emergency Contingency Advisor**: Auto-calculated safety cushion to protect groups from unexpected surge pricing.
- **Debt-Bailout Transfer**: Transfer upfront liabilities from a member who cannot pay to a sponsoring member with internal repayment tracking.
- **Individual Member Ledger**: Itemized breakdown showing exact contributions per member.
- **Dark/Light Mode**: Smooth curtain transitions with full responsiveness.

## 🛠️ Built With
- HTML5, CSS3, Tailwind CSS
- Vanilla JavaScript (ES6+)
- FontAwesome Icons
